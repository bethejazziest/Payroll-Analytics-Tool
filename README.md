# Payroll-Analytics-Tool
A Java/JavaFX desktop tool that parses and analyzes the 2023 Massachusetts State Payroll dataset (44MB!). Loads and structures tens of thousands of records, merges employee jobs, and provides fast search by name, dept, job title, ID, &amp; MORE with real-time UI updates and extensible analytics.

This project is a Java and JavaFX desktop application designed to load, organize, and analyze the 2023 Massachusetts State Payroll dataset, a large CSV file of approximately 44 MB containing tens of thousands of employee and job records. The program reads the dataset line by line, extracts each employee’s identifying information, and converts each row into a Job object containing the position title, department or division, role type, and total pay for that specific entry. Employees with multiple job entries are automatically merged by matching their ID numbers, allowing the system to build a complete representation of each employee, including the number of jobs held, their combined salary across all positions, and the highest-paying job they performed during the year. All data is maintained in in-memory structures consisting of Employee objects backed by dynamic lists of Job instances.

The application includes a user interface implemented with JavaFX and FXML. The UI allows the user to load the payroll file through a file chooser and provides live status messages as the dataset is read, validated, and processed. As the file loads, the program gracefully handles malformed numeric fields, missing values, and other irregularities by updating the status label using JavaFX’s application thread. After loading is complete, the user can perform targeted searches against the dataset. The search engine is implemented through Java Streams and supports queries by first name, last name, full name, or employee ID, as well as searches by department and exact job title. These operations return filtered lists of employees, and the interface displays how many results matched the criteria. Each search inspects the employee’s job history and determines whether any of their positions match the requested department or title, enabling accurate retrieval even when employees hold multiple roles across different organizational units.

Together, these components form a complete data-processing pipeline, beginning with file ingestion, followed by structured modeling of employees and jobs, and ending with an interactive interface for exploring public payroll information. The project demonstrates proficiency in Java file I/O, object-oriented design, large-dataset handling, JavaFX application development, multithreaded UI updates, and functional programming using the Streams API. It serves as an example of transforming raw public data into a usable, searchable, and extendable analytical tool.
